# Güncel kullanım

Artık yalnız **ana** ve **hızlı** görev var. [Tek kullanım rehberi AKIS.md](AKIS.md).

- `python -m safak_gorev2.competition.main --task ana --mode observe`
- `python -m safak_gorev2.competition.main --task hizli --mode observe`

Eski üç seçenek arşive taşındı; eski profil isimleriyle başlatılmaz. Hızlı görev durmadan bırakmaz, MOSSE kullanmaz. Gerçek uçuş koşulları ve profil alanları rehberde açıklanmıştır.
